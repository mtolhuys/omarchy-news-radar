# Omarchy News Radar 0.1.6

This release makes the normal Omarchy plugin update path actually repair the background-window activation defect for existing installations.

- The runtime generation loaded by Omarchy's post-update plugin rescan now migrates Radar's byte-exact unmodified 0.1.3 managed shortcut from `toggle` to `summon`.
- The migration keeps the established private backup, atomic write, Hyprland reload/config validation, and exact rollback guarantees.
- The automatic command cannot install a shortcut when `Super+Alt+N` is free and leaves personal, edited, conflicting, multiple, symlinked, or ambiguous configuration unchanged.
- **Update shortcut** remains available inside Radar as a visible retry if automatic validation cannot complete.
- Disposable-VM acceptance now reproduces the released 0.1.3 failure and proves that running only the official update command repairs the live shortcut before Radar is opened.

Fresh shortcut setup remains explicit. Omarchy's separate `Super+Shift+N` Editor action is never changed.
