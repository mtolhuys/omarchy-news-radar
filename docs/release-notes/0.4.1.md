# Omarchy News Radar 0.4.1

QoL for unread filtering and shortcut discovery without a schema bump.

- Each section header exposes an **All** / **Unread only** chip beside **Mark all as read** and **Settings**; it toggles the existing persistent `unreadOnly` filter.
- Press `f` on the reading surface to flip the same flag (ignored while Settings, preferences, or search editing are active).
- The Settings **Unread only** chip is unchanged and stays in sync.
- A subtle collapsible **Keys** footer under the story list shows compact keycaps for Esc/q, j/k, Enter/o, s, u, f, /, r, Tab, 1–6, Home/End, and ?. It starts open; collapse is remembered for the session only. Toggle with the **Keys** control or `?`.
