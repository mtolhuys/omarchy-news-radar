# Omarchy News Radar 0.5.2

Status: release approved after local owner testing.

For You now opens straight into personal news. It matches enabled plugins and followed projects or creators; older whole-source follows remain clearable but no longer duplicate Plugins here or populate new briefing candidates.

Sidebar numbers mean unread stories, with an explicit heading. All and Unread only keep the same unread badge, and the reader explains how many read stories the filter hides. Settings and the section heading have room even in a narrower window.

Reading history, saved stories, filters, mutes and the current briefing are preserved. No feed/state schema, endpoint, dependency or installation permission changes.
