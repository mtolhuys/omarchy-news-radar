# Omarchy News Radar 0.5.13

This release tightens the notify-only update check from 0.5.12 so it writes nothing inside the installed plugin.

0.5.12 already removed every install path: Radar reports a newer release and points you to the Omarchy plugin marketplace. To learn whether a newer release exists, though, it still downloaded the repository's latest commit into the installed plugin's own `.git` folder. It never installed or ran that commit, but a marketplace reviewer's finding named fetching as well as installing, so this release removes that too.

The check now reads the plugin's origin address, fetches only the latest commit into a temporary repository outside the plugin, reads the version there, and throws the temporary repository away. Nothing inside the installed plugin is written, not even Git's `FETCH_HEAD` marker, and the fetch no longer inherits the installed checkout's local Git configuration or hooks. Because the origin address is now passed to Git directly, the check refuses anything that is not a plain repository address. The fetch downloads only the latest commit, has a 30-second limit, and never waits for a credential prompt.

Local state schema remains v13 and no migration runs. Feed schema remains v2, insights and setup-news remain v1, and the helper protocol remains v1.
