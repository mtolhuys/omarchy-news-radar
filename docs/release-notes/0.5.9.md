# Omarchy News Radar 0.5.9

This emergency patch restores the update interface after version 0.5.8 emitted helper protocol version 2 while the QML client accepts protocol version 1. The feed, saved stories, read state, filters, briefing, and window settings were not affected.

Every update-status and update-apply response now imports the repository-wide `HELPER_PROTOCOL_VERSION` constant instead of declaring a separate updater protocol. A cross-language regression test reads the QML parser and Python updater together, so CI fails if their accepted and emitted versions diverge or the updater introduces another private protocol constant.

Release-aware update behavior from 0.5.8 remains intact: only a strictly greater manifest release version produces a desktop update, and same-version Forge collector or documentation commits stay silent.

Existing 0.5.8 installations can recover through Omarchy's official updater:

```bash
omarchy-plugin-update io.github.mtolhuys.news-radar --yes
```
