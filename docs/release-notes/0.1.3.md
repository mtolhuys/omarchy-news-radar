# Omarchy News Radar 0.1.3

This reader update makes it practical to clear a busy section while improving the usefulness and reliability of plugin stories.

- Each section now has an explicit **Mark all as read** button beside Settings. It atomically marks every unread story matching that section's persistent filters, including unloaded pages, while temporary search and unrelated sections remain untouched.
- Plugin additions, releases, verification changes, and retirements now use the marketplace's current validated description when available instead of repeating the change already stated by the title and metadata.
- A per-story read action that races with a successful feed replacement is now treated as a benign stale action; the new validated edition stays current instead of showing a false failure.
- The complete reader, state transition, source-enrichment, and disposable-desktop paths remain covered by deterministic tests and Omarchy Plugin Lab acceptance.
