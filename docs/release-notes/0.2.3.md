# Omarchy News Radar 0.2.3

This release moves the live feed origin from GitHub Pages to the maintainer site so Forge owns collect → build → serve.

- Clients fetch `https://mtolhuijs.nl/storage/news-radar/events.json` (same-origin image assets under that path).
- RSS channel links point at the same storage URL.
- GitHub Actions publication remains available as an optional backup; scheduled delivery no longer depends on Pages propagation.
