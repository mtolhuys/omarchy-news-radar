# Omarchy News Radar 0.2.1

This corrective release keeps the v0.2.0 navigation and news-reliability fixes while returning the reader to a calm, news-first surface.

- Normal successful use no longer shows local/published edition mode, source pipeline status, publication/cache timestamps, Pages propagation details, or runtime version copy.
- The always-visible keyboard legend is removed; shortcuts remain available through focused controls, tooltips, and the documented keyboard map.
- Search now says **Search news**, and section summaries show only active filters, relevant just-read context, story count, and unread count.
- Network or publisher trouble does not replace usable cached news with diagnostics. A concise recovery message appears only when no valid news is available.
- README release status and installation guidance now identify the current published version correctly.

All v0.2.0 fixes for Load more, held-arrow navigation, Unread only stability, background feed adoption, activation, unread discovery, and publication continuity remain included.
