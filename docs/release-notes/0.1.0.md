# Omarchy News Radar 0.1.0

The first public release turns current Omarchy releases and plugin-marketplace changes into a visual, keyboard-first reader with a validated live feed, safe image previews, useful engagement metrics, and offline cache behavior.

Highlights:

- Every story is visibly `UNREAD` or `READ`, with durable per-story state, exact section/newspaper counts, and reversible `u` / inspector controls. Opening, refreshing, hovering, and closing never bulk-mark an edition.
- The optional default-on newspaper widget shows unread and source-health status and can be hidden with zero bar gap, then restored from Tune.
- The normal movable, resizable, maximizable panel supports `Alt+Tab`, section cycling with `Tab`, keyboard story navigation, finite Load more pagination, local search, saved stories, and private interest matching.
- Marketplace images are mirrored as bounded same-origin assets. Views, hearts, command copies, repository stars, and release downloads use compact accessible icons; plugin stories link to their human marketplace page.
- `Super+Alt+N` and the Apps-menu entry are explicit, reversible opt-ins. The helpers refuse personal, modified, ambiguous, symlinked, or unrelated configuration.
- Collection, publication, state migration, and lifecycle behavior are covered by 72 offline tests, strict repository validation, and disposable Omarchy Plugin Lab acceptance.

Install:

```bash
omarchy plugin add https://github.com/mtolhuys/omarchy-news-radar --enable --yes
~/.config/omarchy/plugins/io.github.mtolhuys.news-radar/bin/news-radar-launcher install
```

The panel is available without a shortcut:

```bash
omarchy-shell shell toggle io.github.mtolhuys.news-radar
```

See the README for the optional conflict-checked `Super+Alt+N` helper, local data, and exact removal order. Omarchy News Radar is an independent community project; marketplace verification is not a security audit.
