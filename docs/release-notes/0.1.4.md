# Omarchy News Radar 0.1.4

This reliability update makes publication state honest and fixes the one-invocation activation glitch.

- Publication now gets four off-peak best-effort GitHub schedule opportunities per hour. Radar separately exposes source checks, collection, artifact publication, Pages' documented cache window, and local cache time, and warns when publication is more than 90 minutes old.
- **Refresh** is now **Check for updates**. `R` and newspaper middle click check the static published edition and report the adopted new-story count, no newer edition with publication age, stale publisher, invalid edition, or offline last-known-good result.
- Newspaper click, `Super+Alt+N`, and the Apps entry now share summon-to-focus behavior. Closed Radar opens; obscured or foreground Radar raises and stays open; rapid repeats retain one window. Deliberate close routes are unchanged.
- Dense-list keyboard navigation no longer parks a selected story against or underneath the window bottom. Crossing the viewport edge eases the complete row to the top, then Down continues through the following visible rows normally.
- Regression tests cover scheduling, publication boundaries, new/no-change/stale/offline results, exact story counts, launcher parity, focus dispatch, and repeat activation. The full behavior is exercised in a disposable Omarchy Plugin Lab with real QMP pointer and global-shortcut input.
