# Omarchy News Radar 0.5.1

Status: published 6 September 2026.

Version 0.5.1 completes the keyboard-first interaction model introduced in 0.5 and turns My setup into a useful local inventory even when public release-note coverage is unavailable.

## Complete keyboard access

- Arrow keys navigate every action and included-project card in project, collection, and context details. `j` / `k`, Home/End, Enter, Escape/`q`, and Page Up/Page Down follow the same roles as the main reader.
- Tune and current-section Settings now support spatial arrow navigation, Home/End jumps, Enter/Space activation, Escape/`q`, and visible key guidance.
- `t` opens Tune. `,` opens Settings for the current section. Search retains both characters while its field is focused.
- On My setup, End or Down from the last card reaches **Read news for your setup**; Up returns to the last plugin and Enter opens the news list.

## A useful view of your setup

- My setup reads each enabled plugin's bounded local manifest description as well as its name and installed version. These facts remain on the device.
- Cards lead with `Enabled · version`; projects with real release history retain their precise current, ahead, or behind status, and available updates sort first.
- Missing public release history is explained once as secondary context. Details no longer display `Published unknown`.
- News for you states how many enabled plugins are tracked, even when only a few of them have an eligible event in the current edition.

## Clearer page structure and counts

- Subtle dividers separate the briefing, reviewed collections, and project discovery without adding another box around the page.
- Rail numbers always mean total matching stories. An amber dot means at least one is unread; hover or assistive text gives both exact counts.

## Honest briefing refresh

- A completed Front Page remains visible as a read edition instead of collapsing into empty space.
- When another unread briefing can be composed, Radar announces it and offers **Load new briefing**. The completed edition stays in place until that explicit choice.
- When no eligible unread candidates exist, the same place offers **Check for new stories**. It refreshes the published edition and exposes **Load new briefing** if eligible unread arrivals are found.
- Radar never marks completed stories unread or manufactures a new briefing during a quiet period.

## Recoverable empty sections

- When local mutes hide every matching story, the empty section names the cause and reports how many stories are hidden instead of looking like an empty edition.
- **Review mutes** opens the existing local choices screen, and Enter activates the recovery action without requiring a pointer.

Feed schema v2, insights schema v1, private state schema v13, plugin identity, entry points, shortcut ownership, launcher behavior, and removal behavior are unchanged from 0.5.0.
