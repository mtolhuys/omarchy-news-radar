# Omarchy News Radar 0.3.0

This release moves clients onto rate-limited Laravel feed routes and stops hosting marketplace preview rasters on the feed VPS.

- Clients fetch `https://mtolhuijs.nl/news-radar/events.json`.
- Story images use allowlisted marketplace HTTPS `sourceUrl` values (`https://plugins.omarchy.org/assets/img/plugins/…`) after publisher validation; Forge no longer mirrors WebP/PNG/JPEG into `assets/images`.
- Per-IP limits protect the Forge VPS: 30/min for feed documents, 120/min for residual static assets such as `site.css`.
