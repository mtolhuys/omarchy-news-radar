# Omarchy News Radar 0.5.7

Status: patch release for Saved bookmark durability after owner-directed merge of issue #15.

Saved no longer depends on the rolling feed still carrying a bookmarked event. When a saved id is absent from the current edition, Radar restores a degraded row from the persisted save record so the title and original source remain reachable. Live feed copies stay authoritative when still present. No permissions, dependencies, network origins, install hooks, privilege escalation, or background services were added. Feed schema remains v2; insights remain v1; setup news remains v1; private state remains v13.

Source unit coverage for the regression is included. Marketplace verification remains maintainer-controlled and is not a security audit.
