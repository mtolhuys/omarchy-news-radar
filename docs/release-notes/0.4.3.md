# Omarchy News Radar 0.4.3

Layout correction and Mark-all shortcut on top of 0.4.2, without a schema bump.

- Move the collapsible **Keys** legend to the footer of the left **SECTIONS** rail (was under the story list in 0.4.1/0.4.2).
- Widen the SECTIONS rail a touch (13% → 15% wide / 20% → 22% narrow; max cap 168 → 184) so labels and counts are comfortable without empty gutters.
- Slim the center list (52% → 48% / 74% → 72%) and widen the detail inspector (27% → 31%) so the news body and actions get the freed width.
- Keyboard `a` triggers **Mark all as read** for the current section (same as the header button); documented in the Keys legend and UX map.
