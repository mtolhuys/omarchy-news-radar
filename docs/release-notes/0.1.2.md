# Omarchy News Radar 0.1.2

This focused reader update improves discoverability and removes settings that weakened section identity.

- The keyboard guide now sits directly below search. Refresh shows its `R` shortcut on hover.
- Down from the final visible story focuses **Load more** and changes the label to the exact Enter action; Enter reveals the next twelve stories and the next Down enters that page.
- Section renaming and its hidden profile state are gone. Settings keeps fixed source disclosure and only the filters that actually change the story list.
- Meaningful secondary text now derives from the panel foreground, keeping summaries, dates, status, counts, and metadata legible in light and dark themes.
- Plugin-addition stories use the marketplace's validated explanation text when available instead of repeating a generic listing sentence.
- State v9 migrates v1–v8 atomically and preserves every supported filter, display preference, save, and per-story read override.
- The README preview now uses Omarchy's Matte Black theme and an unobscured, exact-window crop from the disposable Plugin Lab.
