# Omarchy News Radar 0.5.5

Status: release approved after local owner testing.

Radar now gets out of the way when another application takes focus. Hyprland keeps floating windows above tiled windows, so changing keyboard focus alone could leave the large Radar frame covering the browser, terminal, or application the user had selected. Radar now dismisses through its normal lifecycle after a confirmed focus transfer.

The newspaper, Apps entry, and `Super+Alt+N` reopen exactly one focused Radar window. Durable local reading state, saves, filters, briefing membership, and window geometry remain intact. Mapping-time focus changes are ignored until Radar's exact compositor identity has received focus, preventing startup races.

All 329 source tests and repository validation pass. Full disposable Omarchy acceptance covered competing windows, Alt+Tab, newspaper and shortcut reopening, read/unread state, filtered **Mark all as read**, failure handling, scaling, themes, hot update, disable/re-enable, and removal. The released-0.1.3 upgrade journey also passed. The owner tested the exact runtime on the daily desktop and approved release. Marketplace verification remains maintainer-controlled.
