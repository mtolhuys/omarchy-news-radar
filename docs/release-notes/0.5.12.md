# Omarchy News Radar 0.5.12

This release makes the plugin-update check notify-only. Radar still tells you when a newer release exists, and it no longer installs anything from inside the panel.

Since 0.5.8 the panel's **Update plugin** control ran Omarchy's official updater, which fast-forwarded the plugin to whatever the repository's default branch named at that moment. The marketplace verifies one exact commit, and the default branch is mutable, so that control could install code the marketplace had not reviewed. A marketplace reviewer blocked verification on exactly that, with the instruction to keep update checking notify-only.

The check keeps its release boundary: it compares strict manifest versions, so collector, documentation and server commits stay silent. A newer release now shows a plain notice pointing at the Omarchy plugin marketplace, where you install it once that release is verified. The **Update plugin** and **Retry update** controls, the `update-apply` helper command, and every call to `omarchy-plugin-update` are removed. The check runs only read-only Git operations and never moves the installed checkout.

This release also carries 0.5.11 unchanged: dismissed Omarchy News stories stay read when the rolling edition evicts and rematerializes them, and a Core retention floor keeps recent official news in the edition.

Local state schema remains v13 and no migration runs. Feed schema remains v2, insights and setup-news remain v1, and the helper protocol remains v1.
