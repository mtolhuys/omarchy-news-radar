# Omarchy News Radar 0.1.7

This release fixes unstable dense-list navigation and corrects a publication-state defect that repeatedly made older marketplace changes look newly discovered.

- Pagination now keeps the selected story and exact viewport position stable while the next bounded page is added.
- Per-story read-state refreshes no longer fight an active keyboard scroll animation.
- Deferred positioning from an older navigation request is ignored once a newer request owns the viewport.
- The first Down after pagination smoothly top-aligns the first newly revealed story when needed; the following Down continues normally without moving that anchor.
- Holding Up through a long list now keeps every selected story visible instead of allowing key repeat to run above the viewport.
- Disposable-VM acceptance samples the viewport throughout pagination and verifies both post-load navigation steps.
- Scheduled builds now restore source state from the latest successfully deployed run and fail closed when continuity is unavailable.
- Repeated local live collections keep a private advancing source baseline, and deterministic event timestamps cannot be refreshed by rediscovery.
- Front Page shows only the newest official Omarchy release instead of injecting several historical releases into the current edition.

The public feed schema, read-state schema, plugin identity, shortcut, and bar widget remain unchanged. The internal source snapshot advances to schema v2 to make the one-time contaminated-history reset explicit.
