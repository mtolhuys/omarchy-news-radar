# Omarchy News Radar 0.4.0

This release adds a dedicated YouTube lane for Omarchy-related videos.

- Forge collects through the allowlisted YouTube Data API v3 when `YOUTUBE_API_KEY` is set; missing keys and API failures fail closed and retain the prior YouTube snapshot.
- The reader rail is Front Page · For You · Core · Plugins · YouTube · Saved (`1`–`6`).
- Feed schema version 2 carries `youtube-video` events with allowlisted `i.ytimg.com` thumbnails and `youtube-views` / `youtube-likes` metrics. Ranking stays inside the YouTube section only.
- Local state migrates to schema v10 and adds the YouTube section filter. Opening a video uses the normal browser open path—no embed or scrape.
