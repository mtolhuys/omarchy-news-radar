# Omarchy News Radar 0.5.10

This patch restores control over Saved stories that the publisher no longer carries in the rolling feed. Those stories were correctly reconstructed from the bounded local save record for display, but the mutation handlers still required current-feed membership. **Mark read** therefore returned a stale result and **Unsave** rejected the visible story.

The reading and bookmark action boundary now reconstructs the same strict local event used by Saved projection. Feed-absent Saved stories can be marked read or unread, included in **Mark all as read**, and removed with **Unsave**. Unsaving an archived story also removes its now-unreachable explicit read override.

This does not permit actions on arbitrary missing stories. An event must still exist in the validated reading feed or in the validated bounded Saved records. Feed, setup-news, insights, helper protocol, and private-state schemas are unchanged.
