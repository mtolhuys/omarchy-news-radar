# Omarchy News Radar 0.1.5

This patch repairs the upgrade path that left some 0.1.3 users on the old close-on-repeat shortcut after installing 0.1.4.

- Radar now distinguishes its exact unmodified legacy `Super+Alt+N` block from edited or ambiguous configuration.
- Opening Radar performs a read-only check and, when that legacy block is present, shows **Update shortcut**. The binding changes only after that explicit action.
- Migration replaces only Radar's owned `toggle` statement with `summon`, preserves every surrounding byte, creates a private backup, validates the Hyprland reload and live action, and rolls back on failure.
- Exact current and legacy Radar-owned blocks can both be removed safely. Personal, edited, conflicting, multiple, symlinked, or otherwise ambiguous bindings remain refused, with no force option.
- A dedicated disposable-VM upgrade test installs released 0.1.3, reproduces the background close, fast-forwards to 0.1.5, drives the rendered migration, and verifies the live global shortcut and real newspaper click against an obscured and foreground Radar window.

The 0.1.4 newspaper source already used summon correctly; the upgrade test independently confirms it raises the existing window. The persistent regression was the old user-owned binding that normal hook-free plugin updates intentionally did not rewrite.
