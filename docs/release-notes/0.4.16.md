# Omarchy News Radar 0.4.16

## Highlights

- A fresh panel open now marks exactly the first visibly presented selected story as read without requiring a navigation detour or pointer click.
- The automatic transition uses the existing durable per-story state path and keeps the active row in place under **Unread only**.
- Re-summoning an open panel, refreshing, reprojecting a section, changing focus, and receiving later stories do not trigger another automatic read.
- Restored source snapshots are validated without consulting the host date; rolling event retention is applied only to the successor at the explicit collection time.

## Notes

- Deliberate selection and the `u` shortcut retain their existing one-story behavior, including reversing the automatically read story to unread.
- Feed schema remains v2 and local state schema remains v11.
- Snapshot validation still rejects malformed events, duplicate IDs, non-canonical ordering, and more than 500 events; no schema change is required.
