# Omarchy News Radar 0.5.6

Status: release approved after owner review of the reported Omarchy 4.0.3 regression and its exact fix.

Radar now resolves its bundled client, shortcut helper, and logo from the QML entry points themselves. Omarchy 4.0.3 no longer exposes private plugin source metadata to third-party panels and bar widgets; relying on that metadata left helper commands empty, kept the newspaper hidden, and prevented the panel from loading its feed.

The file-relative resolver works independently of the plugin installation directory and fails closed for non-file URLs. It does not add permissions, dependencies, network origins, installation hooks, privilege escalation, or background services. Feed schema remains v2, insights remain v1, setup news remains v1, and private state remains v13.

All 329 source tests, repository validation, QML validation against the Omarchy 4.0.3 source, and GitHub CI pass. A disposable 4.0.3 VM confirmed the newspaper, background refresh and unread propagation, middle-click refresh, and panel opening. A separate public-clone journey installed the exact release candidate from GitHub and passed Apps entry, welcome, Front Page, read-state, shortcut, close, cleanup, and removal checks. Marketplace verification remains maintainer-controlled and is not a security audit.
