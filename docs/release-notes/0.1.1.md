# Omarchy News Radar 0.1.1

This release hardens the first public reader before marketplace review completes.

- Local installations created by `make local-latest` no longer remain frozen on one owner-built edition. Refresh checks the hosted feed, never downgrades newer local data, and adopts a newer published edition atomically.
- Down from the final visible story now focuses **Load more**. Enter loads the next twelve results without marking a newly revealed story read, and the next Down selects the first new result.
- Refresh shows a small animated progress indicator while the cached edition stays usable.
- The nonfunctional manual interests control and its unused runtime path are removed. `For You` now has one honest rule: exact enabled-plugin matches detected locally.
- State v8 migrates v1–v7 atomically and preserves every supported preference, filter, section name, save, and per-story read override.
