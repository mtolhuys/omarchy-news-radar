# Omarchy News Radar 0.2.2

This correctness release makes the top-bar newspaper advertise only unread stories the current newspaper can actually reveal.

- The badge now deduplicates unread event IDs across Front Page, For You, Core, Plugins, and Saved after their persistent Settings filters are applied.
- Stories hidden by every section no longer leave a misleading nonzero badge, while changing a filter can reveal and begin counting them again.
- Front Page and For You use the same exact enabled-plugin IDs in the bar calculation as in the panel.
- The bar reloads those IDs for every coalesced calculation instead of retaining a lifetime-stale enablement snapshot.
- The regression suite reproduces the reported failure mode where image-less unread plugin stories were excluded from every visible section while the bar still reported them.

The disposable-VM journey verifies the bar's unread-update plumbing, rendered filters, normal unread discovery, activation, themes, navigation, runtime replacement, and clean removal; the focused integration regression verifies the exact filtered-badge calculation.
