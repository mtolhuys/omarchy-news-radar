## Disposable Omarchy 4.0.3 acceptance

Plugin Lab run `20260910-213121` used the Omarchy 4.0.3 ISO and exact source checkout. Machine assertions confirmed that the newspaper occupied one visible right-section slot, background refresh cached a valid edition and propagated its unread count while the panel was closed, background helpers exited, middle click performed one bounded refresh, and left click opened the panel. That later companion failure does not establish broad acceptance for the release, but it occurred after every helper-path behavior relevant to this regression had passed.

## Safety and compatibility

- Both QML entry points derive the plugin root from `Qt.resolvedUrl("../")`, decode a local file URL, and return an empty path for unsupported or malformed URLs.
- The fix does not hardcode the normal Omarchy plugin directory and remains valid for other checkout locations.
- No feed or state schema, endpoint, permission, dependency, network origin, installer behavior, daemon behavior, or user-configuration mutation changed.
