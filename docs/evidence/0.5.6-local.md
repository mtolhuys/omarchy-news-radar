## Safety and compatibility

- Both QML entry points derive the plugin root from `Qt.resolvedUrl("../")`, decode a local file URL, and return an empty path for unsupported or malformed URLs.
- The fix does not hardcode the normal Omarchy plugin directory and remains valid for other checkout locations.
- No feed or state schema, endpoint, permission, dependency, network origin, installer behavior, daemon behavior, or user-configuration mutation changed.
