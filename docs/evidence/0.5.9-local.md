# 0.5.9 helper-protocol recovery evidence

Status: candidate under verification. This record must be completed with the exact public commit, source suites, official marketplace checks, GitHub CI, Forge publication, and a temporary-checkout 0.5.8-to-0.5.9 recovery before release completion is claimed.

## Regression and repair

- Root cause: `radar/plugin_update.py` emitted a private protocol version 2 while `src/Model.js` accepted the shared helper protocol version 1.
- Scope: the QML update-status/apply response parser rejected the payload; feed retrieval, saved stories, read state, filters, briefing membership, and window state were unchanged.
- Repair: all updater payload paths import and emit `HELPER_PROTOCOL_VERSION`; the updater no longer declares a private protocol constant.
- Prevention: `tests.unit.test_qml_contract` reads both implementations and fails if the QML acceptance check differs from the shared constant, if the updater stops importing that constant, or if a private updater protocol constant reappears.
- Recovery target: a temporary installation at 0.5.8 must detect 0.5.9, apply through `omarchy-plugin-update`, and return a QML-compatible protocol response.
