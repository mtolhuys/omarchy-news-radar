## Safety and compatibility

- Both manifests are read from explicit commit objects and bounded to 64 KiB before JSON parsing.
- Plugin identity and strict three-part release versions are required before comparison.
- Same-version commits bypass cleanliness, topology, and updater availability because there is no client release to apply.
- A real newer release still requires a clean fast-forwardable checkout and delegates mutation to `omarchy-plugin-update`.
- Feed, insights, setup-news, and private-state schemas are unchanged. No new dependency, network origin, permission, daemon, or configuration mutation is introduced.
