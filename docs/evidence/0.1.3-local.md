The rendered local Lab scenario proved the complete paired panel/newspaper lifecycle, exact unread/read persistence, animated refresh, default-on images and indicator, zero-gap indicator hiding and Tune restoration, source opening, human plugin links, responsive resize/maximize, normal Alt+Tab identity, Apps-menu launch, `Super+Alt+N`, and exact owned teardown.

The focused 0.1.3 regression surface additionally proved:

- **Mark all as read** is visibly reachable beside Settings and atomically clears every unread story matching the section's persistent filters, including unloaded pages, without changing a different section.
- Temporary search is excluded from batch scope, while individual read/unread remains reversible and close or refresh never implies reading.
- All 256 current plugin events use the marketplace's validated plugin explanation when available; title, type, version, trust state, event identity, ordering, and metrics remain exact source facts.
- A per-story state action made stale by a concurrent edition replacement is a benign no-op that keeps the new validated edition current.
- The exact public-clone scenario installed the final remote candidate, loaded the fixed Pages edition, opened it through the managed Apps entry and `Super+Alt+N`, persisted only the selected story as read, closed without an owned helper, and removed the shortcut, launcher, and plugin cleanly.

## Deliberate boundaries

- Marketplace submission starts review; only marketplace maintainers can approve and list the plugin, and marketplace verification is not a security audit.
- Plugin explanations use the bounded validated marketplace description. Radar does not scrape arbitrary README pages, invent summaries, or execute remote markup.
- The main plugin remains a paired panel and optional default-on newspaper. AltTab/Omadock icon consumers remain separately released companion integrations.
- Normal removal preserves cache, reading state, and saves. Explicit purge and the documented shortcut/launcher removal order remain intentional owner actions.
