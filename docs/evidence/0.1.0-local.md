## Per-story read-state proof

State v7 stores a fixed migration baseline plus a bounded map of canonical event-ID overrides. A kernel-backed state lock serializes read-modify-write operations across the panel and newspaper helper processes. The UI and bar consume one canonical unread predicate rather than maintaining parallel counts.

The local Lab scenario proved all of the following in the rendered plugin:

- a newly introduced event remains `● UNREAD` after refresh and close;
- opening and closing the panel do not bulk-mark an edition;
- each row visibly says either `● UNREAD` or `✓ READ`;
- the inspector action marks only the selected event;
- `u` reverses that event back to unread;
- section badges and the newspaper count change by exactly one;
- rapid navigation cannot lose or reorder state commands;
- hover does not change selection or reading state;
- read state survives process and panel restarts.

The exact public-clone scenario independently loaded the 80-event Pages edition, selected one published story, persisted only that story as read, reopened via both Apps and `Super+Alt+N`, and removed the managed shortcut before removing the plugin.

## Deliberate boundaries

- Marketplace issue submission starts review; only the marketplace maintainers can approve and list the plugin, and listing is not a security audit.
- Quickshell exposes a shared `org.quickshell` Wayland app ID. Radar declares an exact title/app-ID identity and bundles the newspaper icon, but ordinary system switchers need compatible AltTab/Omadock companion releases to consume that declaration. Those companion changes remain separate from this repository and were not silently published as part of Radar.
- Production currently has no reviewed community records. The schema remains available for future repository-reviewed records without recreating the removed empty Community tab.
- Normal plugin removal preserves cache, read state, and saves. The explicit purge and the documented shortcut/launcher removal order remain intentional user actions.
