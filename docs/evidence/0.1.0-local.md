## Archive policy and deliberate boundaries

Version 0.1 publishes the bounded live edition as `events.json` and as a same-byte monthly archive projection named from `generatedAt`. Each static-tree build is transactional; version 0.1 does not claim cross-deployment retention of earlier monthly files.

No public repository, remote, Pages site, tag, release, marketplace submission, external announcement, or host desktop activation was created. The one remaining distribution gate is the authorized public-clone scenario after the owner publishes the intended repository and identifies the exact expected commit.
