## Archive policy and deliberate boundaries

Version 0.1 publishes the bounded live edition as `events.json` and as a same-byte monthly archive projection named from `generatedAt`. Each static-tree build is transactional; version 0.1 does not claim cross-deployment retention of earlier monthly files.

No public repository, remote, Pages site, tag, release, marketplace submission, external announcement, or host desktop activation was created. Production adapters were contract-audited and exercised with deterministic fixtures and bounded loopback/mocked integration tests, but no production collection or publication mutated live services. Public-clone installation remains the one required distribution gate after the owner creates and publishes the intended repository.
