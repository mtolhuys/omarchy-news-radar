## Archive policy and deliberate boundaries

Version 0.1 publishes the bounded live edition as `events.json` and as a same-byte monthly archive projection named from `generatedAt`. Each static-tree build is transactional; version 0.1 does not claim cross-deployment retention of earlier monthly files.

No public repository, remote, Pages site, tag, release, marketplace submission, external announcement, or host desktop activation was created. Quickshell still exposes its shared `org.quickshell` Wayland app ID, so a class-first third-party Alt+Tab plugin may retain its generic Quickshell tile even though Radar now ships a validated application mark and a newspaper-prefixed title; the candidate deliberately does not globally shadow the shared desktop entry. The remaining distribution gate is the authorized public-clone scenario after the owner publishes the intended repository and identifies the exact expected commit.
