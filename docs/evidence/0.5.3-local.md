## Source and storage boundaries

Discovery content is selected from validated plugin additions, plugin version changes and Omarchy releases. Titles, summaries and event dates remain source facts; matching project information and uniquely version-bound notes are optional. The producer no longer loads authored discovery files. The client ignores legacy authored collections while preserving insights-v1 parsing and existing durable URLs.

The only new cache is a bounded, public-only discovery feed snapshot under the existing cache directory and state lock. It is validated on read, symlink-protected, atomically replaced and removed by purge. No network origin, executable hook, dependency, private-data upload or state/feed schema change is added. Mutes, search, source visibility and current retirements still apply during retention.
