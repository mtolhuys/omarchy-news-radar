## Root cause and repair

The panel's initial projection selected and rendered its first story without entering the ordinary durable read mutation. Waiting could therefore never change that row from **UNREAD** until a pointer or navigation action selected it again. A fresh open now arms one bounded one-shot, captures the exact presented event and open generation, and writes that one event through the existing per-story state path after a short stable dwell. Close, modal takeover, explicit navigation, refresh, reprojection, repeated summon, and later arrivals cannot redirect or repeat the action.

Version `0.4.16` also gives this behavior a distinct public identity and aligns current release documentation with the deployed five-minute Forge cadence and the existing direct allowlisted image policy. Feed and local-state schemas do not change.
