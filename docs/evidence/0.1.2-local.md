## Product and regression proof

The rendered local Lab scenario proved the complete paired panel/newspaper lifecycle, exact
unread/read persistence, animated refresh, default-on images and indicator, zero-gap indicator
hiding and Tune restoration, source opening, human plugin links, responsive resize/maximize,
normal Alt+Tab identity, Apps-menu launch, `Super+Alt+N`, and exact owned teardown.

The focused 0.1.2 regression surface additionally proved:

- Down from the final visible story focuses **Load more** with the explicit Enter action; Enter
  adds twelve stories, and the following Down moves into the newly revealed page.
- The complete keyboard guide is visible below search and Refresh exposes `R` on hover.
- Settings contains fixed source disclosure and functional filters only. Section renaming,
  mutable icons/backgrounds, profile state, manual interests, and muted filler are absent.
- State v1 through v8 migrates to v9 without losing filters, bar/image preferences, saves, or
  explicit per-story reading decisions.
- Meaningful secondary text derives from the panel foreground and remains distinguishable in
  maintained light and dark themes, including selected rows.
- All 81 retained plugin-addition stories in the public edition use current validated catalog
  descriptions; zero use the generic “is now listed” sentence.
- Real mirrored story images and compact colored metric icons render while untrusted remote text
  remains plain data.

The exact public-clone scenario independently installed the remote runtime commit, opened it
through both the managed Apps entry and `Super+Alt+N`, loaded the fixed Pages edition, persisted
only the selected story as read, closed without an owned helper, and removed the shortcut,
launcher, and plugin cleanly.

## Deliberate boundaries

- Marketplace submission starts review; only marketplace maintainers can approve and list the
  plugin, and marketplace verification is not a security audit.
- The main plugin remains a paired panel and optional default-on newspaper. AltTab/Omadock icon
  consumers remain separately released companion integrations.
- Normal removal preserves cache, reading state, and saves. Explicit purge and the documented
  shortcut/launcher removal order remain intentional owner actions.
