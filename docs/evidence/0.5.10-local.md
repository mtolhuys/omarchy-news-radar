## Regression and repair

- Root cause: Saved projection reconstructed a feed-absent bookmark from its validated local record, while `toggle_saved_state`, `set_event_read_state`, and Saved batch-read accepted only current-feed events.
- User impact: the restored row remained visible and unread but **Mark read** returned `stale-event`; **Unsave** rejected it as absent from the validated cache.
- Repair: one action boundary combines strict current reading-feed events with strict reconstructed Saved events. Presentation-only metadata is removed before state validation.
- Safety: unknown feed-absent IDs remain rejected. Unsaving an archived bookmark removes only that item's unreachable explicit read override.
